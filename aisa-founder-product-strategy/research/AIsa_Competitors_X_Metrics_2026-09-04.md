## 1. 统一口径

- 粉丝数取账号主页原始显示的完整整数；不把 2.5K 换算成“精确 2,500”。
- 最近五篇指账号截至采集时最新的独立原创帖，包含有原创评论的引用帖；排除纯转发、回复及同串 CTA。置顶帖按实际发布时间决定是否入样，不因置顶自动纳入或排除。
- 表中 Views 为 X 公开浏览计数，不是独立读者、完整阅读次数，也不等同于可访问后台的 impressions/reach。后台曝光、点击、推广占比均未取得。
- 数字从原帖外层互动区域读取，不把被引用帖的互动量算入。零值来自完整互动区域对应零计数；无法读取的值应记 NA，不能当零。
- 平均值为五项总和除以 5；中位数为升序第三项。不同账号五帖覆盖的时间范围不同，且最新帖尚在累积曝光，因此不是同周期增长或内容效果的因果比较。

## 6. 对 AIsa 分发的含义

1. 本样本中 Monid 品牌平均 Views 是 AIsa 的约 9.90 倍，但粉丝仅约 1.35 倍。粉丝基数不足以解释内容触达差异；不能据此推断购买流量、推荐机制或转化率。
2. Monid 的具体工作流演示、成本对比、创始人叙事、品牌引用放大、PH 动员形成连续公开 trace。AIsa 近五帖更偏模型上新、价格/渠道与合作话题。两者不是同一种内容实验。
3. Monid 创始人均值 30,536.6 而中位数 3,290；13.8 万浏览的视频占五帖总浏览约 90.6%。应借鉴可复用的演示方法，而不是拿爆款均值当保底获客预期。
4. AIsa 可以测试“一个具体 Agent 工作流 + 可运行示例 + 成功/失败边界 + 价格与延迟”系列，把社交传播接到首次成功 API 调用。真正产品指标仍应接续看激活、重复调用、付费留存与毛利；本次公开资料不提供这些转化证据。
